# Keep your old documents, pictures and videos safe

**my beloved rubble** looks after a folder of things you don't want to lose. It keeps track of every file in it and
copies them to as many other places as you like: an external disk, a server, Google Drive, S3, Dropbox and dozens more
(anything [rclone](https://rclone.org) can reach). It tells you which files aren't stored in enough places yet, and it
can bring back the whole folder, names and all, if the computer it was on is lost.

The folder stays a normal folder: files open like before, from any program.

> **Two copies is the minimum.** A file that exists in only one place is one broken disk away from being gone. The app
> marks those files in red until they are stored somewhere else too.
